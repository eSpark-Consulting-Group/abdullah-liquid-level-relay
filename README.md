# abdullah-liquidlevelrelay
To design, implement, test and develop all the required documents to produce a full package design of DIN rail type level liquid relay. The product will have 3 different versions.

**Technical Information:**
- Working Temperature Range (-20C to +60C )
- Operating Frequency 50-60Hz
- 3 Levels
- Sensitivity: <100kOhm
